# FinTrust Digital Bank — Customer & Transaction Intelligence

## Project Overview

This project focuses on analysing customer and transaction data from FinTrust Digital Bank, a fictional digital banking organisation created for educational purposes.

The goal is to transform customer and transaction data into useful business intelligence that can support better understanding of customer behaviour, transaction activity, transaction performance and risk-related patterns.

## Business Problem

FinTrust needs better visibility into its customer and transaction data to understand how customers interact with the bank, how transactions are performed across different channels and statuses, and what patterns may require further risk review.

The project therefore focuses on identifying meaningful business questions, defining relevant KPIs and developing analytical outputs that can support data-informed decision-making.

## Project Objectives

The project aims to:

- Understand customer characteristics and behaviour.
- Analyse transaction activity and transaction value.
- Examine transaction channels and transaction statuses.
- Investigate patterns associated with the synthetic risk-review flag.
- Develop meaningful KPIs for management reporting.
- Build an interactive analytical dashboard.
- Communicate findings through clear business insights and recommendations.

## Data Sources

The project uses three approved resources provided for the FinTrust educational project:

1. FinTrust Customer Data
2. FinTrust Transaction Data
3. FinTrust Data Dictionary

The data is synthetic and was created for educational purposes.

Raw customer and transaction datasets are not included in this public repository.
